Start with cheaper models (gpt-4o-mini, gpt-5-mini/nano) rather than flagship models.
**Why:** Cost matters — gpt-4o is 10x more expensive than mini. For structured tasks like function calling + Hebrew conversation, cheaper models are likely sufficient.
**How to apply:** Default to cheapest viable model. Only upgrade if quality is clearly insufficient. Always flag cost implications when suggesting models.
